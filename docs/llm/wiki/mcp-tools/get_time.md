# `get_time` MCP Tool

Returns the current time as a text string. Mirrors the behavior of the `time` CLI subcommand.

## Arguments

| Argument | Type | Default | Description |
|----------|------|---------|-------------|
| `utc` | `boolean` | `false` | Return UTC time instead of local time |

## Output

A single text content item with the formatted time string:

```
Saturday May 3 2026 10:45 AM
```

## Implementation

- File: `src/mcp_tools/get_time.rs`
- `NAME = "get_time"` — shared constant used in definition and dispatch
- `Args` struct — `#[derive(Deserialize, JsonSchema, Default)]`, input schema auto-generated by schemars
- `definition()` — constructs the `Tool` with name, description, and schema
- `call()` — deserializes arguments, delegates to `commands::time::format_time()`

The input JSON is deserialized by cloning the arguments map into a `serde_json::Value::Object` before calling `serde_json::from_value`. The clone is necessary because `from_value` consumes its argument.

## Shared logic

Uses `pub format_time()` from `src/commands/time.rs` — the same formatting function used by the CLI `time` command.
